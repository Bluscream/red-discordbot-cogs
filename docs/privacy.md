# Privacy Policy: Bluscream bot

Last updated: 2026-11-11

This policy covers the Discord bot **Bluscream** (application ID `847471422758584320`), a
privately run [Red-DiscordBot](https://github.com/Cog-Creators/Red-DiscordBot) instance.

## What the bot receives

Like every Discord bot, it receives events from the servers it is in: messages, member joins and
leaves, roles, voice state changes and presence updates. Most of this is processed in memory and
not stored.

## What the bot stores

- **Server settings** chosen by server staff (prefixes, channels, roles, toggles).
- **Moderation records**: modlog cases and warnings, with the user ID, reason and moderator.
- **Scam reports**: when a moderator softbans a scam account, the reported message's text and
  attachments, the user's ID, account age and join date are posted to that server's report
  channel so moderators keep the evidence after the messages are purged.
- **Feature data** for features a server enables, such as birthdays or economy balances, keyed
  by user ID.
- **Logs** on the operator's server for troubleshooting, kept for a limited time.

The bot does not sell or share data with third parties and does not use it for advertising or
AI training. Data is stored on a private server operated by the bot's owner in Germany.

## Your rights

You can ask for your stored data or for its deletion. Red-DiscordBot supports deleting a user's
data on request (`[p]mydata`). Moderation records can be kept where a server needs them to
enforce its rules. Messages posted to a server's channels are controlled by that server's staff.
